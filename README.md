# Stark Group VMS — Frontend (Flutter Web)

Web frontend for the **Stark Group Vehicle Management System (VMS)** built with Flutter Web.

## Prerequisites

- Flutter SDK installed and configured in PATH (`flutter --version`)
- A modern web browser (Chrome / Edge)
- Backend REST API running (default port `9001` or configured base URL)

## Setup & Run

1. Ensure the backend service is running and check the API base URL configuration (`lib/config/api_config.dart`).
2. Install dependencies:
   ```bash
   flutter pub get
